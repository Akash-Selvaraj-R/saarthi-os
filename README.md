# SAARTHI OS

### The Action Agent for Bharat 🇮🇳

> **You have a problem. SAARTHI takes it from here.**

SAARTHI OS is an AI-powered action agent designed to turn messy real-world problems into **structured, executable workflows**.

Instead of simply answering questions, SAARTHI understands the user's intent, reasons about the problem, creates a plan, uses the appropriate tools, performs supported actions, verifies the result, and delivers a clear **next move**.

## ⚡ What is SAARTHI?

Most AI assistants stop at:

> **“Here is your answer.”**

SAARTHI is designed to continue:

> **Understand → Reason → Plan → Use Tools → Act → Verify → Deliver**

A user can describe a problem naturally, without knowing which service, document, website, form, or process they need.

SAARTHI converts that problem into an actionable workflow.

### Example

**User:**

> “My scholarship hasn't arrived and I don't know why.”

SAARTHI can:

```text
UNDERSTAND
↓
Identify the user's actual problem

REASON
↓
Determine possible causes and required information

PLAN
↓
Build a sequence of actions

USE TOOLS
↓
Search knowledge
Check eligibility
Analyze documents
Check deadlines

ACT
↓
Generate the required request/checklist

VERIFY
↓
Validate the generated action

DELIVER
↓
Provide the user's next move
```

The goal is simple:

### **Don't just tell people what to do. Help them move forward.**

# 🔐 Action Safety

SAARTHI distinguishes between:

### INFORMATION

Actions that provide information or generate recommendations.

and

### EXTERNAL ACTIONS

Actions that could affect the user's accounts, applications, communications, payments, or submissions.

External actions should require appropriate user confirmation before execution.

The principle is:

> **AI can prepare the action. The user remains in control of consequential actions.**
